### 🚀 项目简介

**AUAK AGENTY** 是一个基于 Firebase 云后端的手机智能体系统。  

它可以让**视觉模型或大语言模型（LLM）**，通过调用手机的**窗口函数与系统交互接口**，自动完成真实的手机操作。

例如，AI 可以：

* 启动某个视频软件

* 搜索关键词

* 自动点击、滑动、输入

* 像人一样操作手机

* 并在界面中**实时记录每一步操作过程**

这是一个真正的 **“AI 控制手机”** 项目。

* * *

### 🧠 工作流程

1. 用户输入任务（如：打开抖音搜索“AI 新闻”）

2. 模型解析界面并规划步骤

3. 调用系统窗口操作接口执行点击

4. 每一步显示在实时 Step 条中

5. 直到任务完成
